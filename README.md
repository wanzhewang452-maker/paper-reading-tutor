# 论文带读 SKILL 使用说明

这个分享包把一套中文论文学习流程整理成可复用的技能：从科学问题和前代不足开始，沿着真实模型数据流，讲清模块设计、公式、shape、创新证据和模型演进关系。

## 包内文件

```text
paper-reading-tutor/
├── SKILL.md
└── agents/
    └── openai.yaml
论文带读SKILL-使用说明.md
```

SKILL 是写给 AI 助手执行的教学指令。文件自带完整流程，不包含原使用者的聊天记录、私人路径、账号或论文学习进度。

## 使用方法

在支持本地 Codex skills 的环境中，将 `paper-reading-tutor` 整个文件夹放到自己的 `~/.codex/skills/` 中；如果配置了其他 `CODEX_HOME`，则放到该目录下的 `skills/`。Windows 默认位置通常是 `C:\Users\你的用户名\.codex\skills\paper-reading-tutor\`。在能发现该技能的会话里，用下面的指令调用。

其他支持自定义技能的 AI 工具，按该工具的技能导入方式导入 `SKILL.md`。不支持技能导入时，也可以直接把 `SKILL.md` 的正文作为教学指令发给 AI，再提供论文。

## 示例指令

互动带读：

> 请用 $paper-reading-tutor 带我读这篇论文。我是初学者，先讲科学问题、前代不足和整体输入输出，再一步步讲模块。每一步都解释 shape，示例数字保持一致。

完整笔记：

> 请用 $paper-reading-tutor 把这篇论文整理成完整 Markdown 学习笔记，包含模块作用、关键公式、shape、实验与消融证据、自画架构图，以及能获取的原论文架构图和来源。

接续学习：

> 请用 $paper-reading-tutor 接着学。我已学过……，目前卡在……，沿用这些符号与示例维度……。先解释这个卡点，再继续。

最好附上论文 PDF、正式链接或正文。这个技能尤其适合交通时空预测论文，也能用于其他机器学习领域；输入形式和符号会根据具体论文调整。

“下一篇”依赖当前使用者自己的学习路线，技能不会预设已经学过哪篇。需要读取文件、查原文或获取原图时，仍取决于所用 AI 工具具备的能力；没有这些能力时，技能要求明确说明信息缺口。
